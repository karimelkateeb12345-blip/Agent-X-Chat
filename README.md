# Agent X - وكيل بحث السلاسل الإباحية

شات تفاعلي متخصص في اقتراح عناوين من سلاسل إباحية حقيقية (Bratty Sis, Moms Teach Sex, Family Strokes...).

## المميزات
- واجهة شات عربية (RTL) بنفس أسلوب الوكيل
- محاكاة بحث بقاعدة معرفة داخلية لأشهر السلاسل
- جاهز للنشر على Vercel

## التشغيل محلياً
```bash
npm install
npm run dev
```
افتح http://localhost:3000

## النشر على Vercel
1. ارفع المشروع على GitHub
2. ادخل على vercel.com → New Project → استورد الريبو
3. Deploy (مفيش إعدادات إضافية مطلوبة)

أو استخدم Vercel CLI:
```bash
npx vercel
```

## ملاحظات مهمة
- هذا **محاكاة بحث** وليس بحث حي من Data18 أو IAFD (لأن معظم المصادر محتاجة scraping معقد وAPI keys).
- العناوين الموجودة في قاعدة البيانات مبنية على عناوين شائعة حقيقية، لكنها ليست قاعدة بيانات كاملة محدثة يومياً.
- المحتوى للبالغين فقط (18+).

## تطوير لاحق
لو عايز بحث حقيقي:
- أضف API key لـ ThePornDB أو prdb.net
- أو اعمل serverless function تعمل scraping (مع مراعاة ToS وCloudflare)
